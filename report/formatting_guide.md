# 正式報告排版規格

本規格是本專案暫用的編輯選擇，不是學校或期刊的官方格式。有指定範本時，以指定範本為準。

## 文件結構

封面 → 摘要與關鍵詞 → 自動目錄 → 正文第 1–6 章 → 參考文獻 → 附錄。

正文使用 [research_findings.md](research_findings.md)。封面姓名、系所及指導老師等欄位須由作者補齊。目前 Markdown 已整理章節與圖表編號，尚未產生具固定頁面排版的 Word 或 PDF。

## Word 排版設定

| 項目 | 暫用規格 |
|---|---|
| 紙張 | A4，直式，單欄 |
| 邊界 | 上、下、左、右各 2.54 cm |
| 正文字型 | 中文新細明體；英文及數字 Times New Roman |
| 正文大小 | 12 pt |
| 行距 | 1.5 倍行高 |
| 段落 | 首行縮排 2 字元；段後 6 pt |
| 一級標題 | 16 pt、粗體，使用「標題 1」樣式 |
| 二級標題 | 14 pt、粗體，使用「標題 2」樣式 |
| 表格及圖說 | 10–11 pt；表題在上方，圖說在下方 |
| 頁碼 | 封面不顯示；前置頁用小寫羅馬數字，正文從 1 開始 |
| 圖片 | 保持原比例，置中，不超過內文寬度；圖與圖說置於同頁 |
| 參考文獻 | 統一格式、懸掛縮排；引用與條目逐一對應 |

不以空白字元或連續 Enter 排版；使用樣式、分頁與分節功能。目錄及圖表交叉引用應使用自動欄位，避免修改章節後頁碼失準。

## 交稿前檢查

1. 補齊封面資料，確認中文或英文的繳交要求。
2. 確認文中每個表格及圖片都有編號、說明、單位，並在附近文字解釋結果。
3. 保留統計定義：三 seeds、樣本標準差、配對差值；不可把 SD 改稱信賴區間。
4. 按繳交要求統一參考文獻格式；目前原始來源已列出，尚未套用特定期刊格式。
5. 匯出 PDF 後逐頁檢查圖表大小、斷頁、字型、頁碼與目錄。

此次整理只變更文字組織與排版規格，不需要重跑實驗。固定頁數取決於繳交要求與最終排版，不以增加空白或重複內容湊頁數。
